# v1.1 · 2026-11-22

**这一版做了什么：把「Mid-360 倒置、同轴装在云台偏航轴、随云台旋转」这个方案在仿真里做出来并量化验证。**

---

## 核心结论

| # | 结论 | 实测证据 |
|---|---|---|
| 1 | **方案可行** | 云台 180°/s 旋转下端到端导航 `SUCCEEDED` |
| 2 | **必须做 IMU 去畸变** | 180°/s：0.64 m → **0.22 m**（降 64.6%） |
| 3 | **必须处理自遮挡** | 不处理则 **100% 回波是自车**，误差 2.8 m |
| 4 | 内置 IMU 就够 | 同轴旋转无平移，rotation-only 补偿即可 |
| 5 | 倒置有硬约束 | Livox 手册：**安装面离地 ≥ 0.5 m** |

---

## 验证数据

每项为「与真值射线投射标准答案的平均距离误差」（米）。

| 场景 | 原始(naive) | 去畸变 | 改善 |
|---|---|---|---|
| A 静止（对照） | 0.030 | 0.030 | 0%（无旋转即无畸变） |
| **B 180°/s + 去畸变 ON** | 0.644 | **0.299** | **53.6%** |
| B′ 同上，输出栅格 720 束 | 0.632 | **0.224** | **64.6%** |
| **C 180°/s + 去畸变 OFF（对照）** | 0.648 | 0.692 | **−6.9%** |
| D 360°/s + 去畸变 ON | 1.161 | 0.379 | 67.4% |
| E 自车滤波 OFF | 2.823 | 2.810 | 100% 回波是自车 |

**B/C 对比是决定性证据**：同转速下开去畸变显著改善，关去畸变无改善。

## 新增的 7 个 bug（真车上同样会踩）

| # | Bug | 根因 |
|---|---|---|
| 1 | 参数类型崩溃 | launch 传 `0` 被解析为整数，与 double 声明冲突 |
| 2 | 去畸变反而更差 | 参考时刻取帧起始，下游却用帧结束的 TF |
| 3 | **TF 查询静默失败** | 扫描戳超前于最新 TF，`except` 吞异常返回 0 |
| 4 | **单线程执行器死锁** | `lookup_transform(timeout)` 阻塞唯一线程，TF 回调收不到数据 |
| 5 | **多 deque 竞态** | 物理线程逐个 append，扫描线程读到长度不一致的中间状态 |
| 6 | 自车滤波顺序错 | 先 `min()` 再滤波，环境已被覆盖不可恢复 |
| 7 | 未命中值被裁剪 | `np.clip(inf, lo, hi)` 把 `inf` 变成假远墙 |

其中 3、4、5 是并发与时间边界问题，6 是顺序问题——**都比算法错误更值得记住**。

## 已知局限

- 雷达是理想 2D 切片，未建模真实 3D 点云与高度带切片
- IMU 无噪声、无零偏，去畸变效果偏乐观
- 云台锁定/旋转模式切换、底盘自旋联合补偿未单独验证
