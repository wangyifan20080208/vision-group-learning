## 3. 去畸变原理（为什么"只用内置 IMU"就够）

### 3.1 坐标关系

倒置（绕 x 轴 180°）使 y 反向，因此方位角取负：

```
激光系方位角 α  →  云台系 −α  →  base 系  β = θ_g − α  →  世界系  ψ = θ_r + β
```

一帧扫描耗时 100 ms（10 Hz）。云台以 ω 转动时，第 i 束在 t_i 时刻测得，
若被当成 t_ref（帧起始）时刻的朝向解读，就会错位

```
Δθ_i = ∫(t_ref → t_i) ω dt
```

### 3.2 关键一步：用雷达内置 IMU 就够了

雷达与云台偏航轴**同轴**，纯偏航旋转**不产生平移**，只有姿态旋转。
所以只需 **rotation-only** 补偿（这也是 Livox 官方 [`livox_cloud_undistortion`](https://github.com/Livox-SDK/livox_cloud_undistortion) 的做法）。

倒置使 IMU 的 z 轴翻转，故

```
ω_sensor_z = −(θ̇_robot + θ̇_gimbal)
补偿量      α_out = α + ∫(t_ref → t_i) ω_sensor_z dt
```

**注意它同时含底盘转速和云台转速**——所以小陀螺时底盘自旋也能被同一路补偿掉，不需要额外传感器。

### 3.3 三条实现要点（都踩过）

| # | 要点 | 错了会怎样 |
|---|---|---|
| 1 | **参考时刻取消息时间戳**（=帧起始），不是帧结束 | 180°/s 时整体多补 18°，误差翻倍 |
| 2 | **扫描时间戳取帧起始**（真实驱动惯例） | 戳"发布时刻"会让下游 TF 查询超前失败 |
| 3 | **输出栅格比输入密**（如 720 vs 180） | 2° 量化残差约 0.08 m |

## 4. 自遮挡处理（倒置雷达扫到自己）

### 4.1 问题的本质

倒置后 52° 视场朝下，**必然扫到车体**。而二维切片是「**每个方位取最近点**」
（`pointcloud_to_laserscan` 的行为）。自车回波约 0.3 m，永远比环境近，于是

```
r = min(r_env, r_ego)  →  整圈都变成自车轮廓，环境信息被覆盖且无法恢复
```

**实测：不处理时，100% 的回波都是自车点，平均误差 2.8 m。**

### 4.2 正确做法：在"取最近点"之前剔除

关键认识：**滤波必须发生在取 min 之前**。有三个位置可以放，优先级如下：

| 优先级 | 位置 | 说明 |
|---|---|---|
| **1** | 三维点云阶段（body filter） | 最干净。可用 URDF 碰撞体（[`robot_self_filter`](https://github.com/leggedrobotics/robot_self_filter)）或按高度带 `pcl::PassThrough` |
| **2** | `pointcloud_to_laserscan` 的 `range_min` | 源码里它是在取 min **之前**跳过近点的，所以有效 |
| 3 | 切完之后的 `laser_filters` | 信息已丢失，无效 |

### 4.3 两类遮挡源，转动关系相反

| 遮挡源 | 固定在哪 | 去畸变后在 base 系 | 能否静态掩膜 |
|---|---|---|---|
| **底盘 / 车体** | 底盘 | **静止** | ✅ 可以 |
| **发射机构 / 相机支架** | 云台 | **随云台旋转** | ❌ 不能 |

**推论**：`laser_filters` 的固定角度滤波（`LaserScanAngularBoundsFilter`）**必然失效**，因为它只能滤掉固定方向的那一类。

**工程解法（推荐）**：把 `range_min` / 自车剔除半径设到 **0.45–0.60 m**，一次覆盖两类。代价是近距盲区变大，但哨兵不会贴墙走，可以接受。

> 我们踩过的坑：第一版把自车回波用 `min()` 和环境回波合并，结果整圈都是自车，
> 再按距离过滤就把所有点滤光了。**顺序错了，后面怎么调都没用。**

### 4.4 倒置的硬性约束（Livox 官方手册）

| 要求 | 出处 |
|---|---|
| 安装无朝向要求，可用底面安装；**倒装时安装面与地面≥0.5 m** | [Mid-360 手册 P11](https://www.manualslib.com/manual/2952267/Livox-Mid-360.html?page=11) |
| 四周留 ≥10 mm 空间保证散热 | Quick Start Guide |
| 建议装在平整金属面（铝合金，≥3 mm 厚） | Quick Start Guide |

**0.5 m 这条会显著影响结构设计**，请机械同学提前评估车高与重心。

## 6. 真车落地清单（按顺序做）

### 阶段 1：机械与电气

- [ ] 雷达光心**与云台偏航轴同轴**，同轴度 ≤5 mm
- [ ] 安装面离地 **≥0.5 m**（倒装硬性要求）
- [ ] **铝合金底板**，厚 ≥3 mm；四周留 ≥10 mm 散热间隙
- [ ] 桌面上电跑 30 min，确认无过热降频

### 阶段 2：驱动配置

- [ ] 配置文件：`livox_ros_driver2/config/MID360_config.json`
      → `lidar_configs[].extrinsic_parameter` 设 **`roll: 180.0`**（单位：度）
- [ ] **切勿双重旋转**：驱动里填了 180°，SLAM 的外参 / TF 里就不要再转一次，
      否则会破坏「LiDAR ↔ 内置 IMU 出厂固联外参」，里程计 2–3 秒内飘飞
- [ ] ⚠️ **驱动的 `extrinsic_parameter` 只作用于点云，不旋转内置 IMU**。
      倒装后 `/livox/imu` 仍是雷达原（倒置）坐标系，需要自己对齐
- [ ] ⚠️ **Mid-360 内置 IMU 加速度单位是 g（静止模长≈1.0），不是 m/s²**，
      静止时倒装应为 `linear_acceleration.z ≈ +1.0`
- [ ] 用 rosbag 实测验证：静止倒装时看 `/livox/imu` 的 z 符号

### 阶段 3：预处理节点（对应 `deskew_node`）

- [ ] 确认点云带**逐点时间戳**：`CustomPoint.offset_time`（ns，相对帧首）或 `PointXYZRTLT.timestamp`
- [ ] 订阅云台 yaw 角（串口/状态话题，**≥200 Hz**）
- [ ] IMU 积分 → 逐束旋转补偿（参考本仓库 `deskew_node.py`）
- [ ] **自车滤波放在切片之前**，半径 0.45–0.6 m
- [ ] 输出 frame 用**不随云台转**的 `base_footprint` / `chassis`

### 阶段 4：切片与导航

- [ ] `pointcloud_to_laserscan` 的 **`target_frame` 必须显式设置**为底盘系。
      留空（雷达系）时，`min_height/max_height` 是在倒置坐标系里切的，
      切出来的是**反向的斜面**，代价地图会出现莫名其妙的障碍
- [ ] 该节点**无法表达帧内旋转**（`time_increment=0`），
      所以**必须先去畸变再切片**，不能指望它补偿云台旋转

### 阶段 5：验收指标（照抄仿真的标准）

| 指标 | 目标 |
|---|---|
| 地图与雷达自洽性 | 平均误差 **< 0.05 m** |
| 云台 180°/s 时的扫描误差 | **< 0.3 m**（不去畸变会到 0.6 m 以上） |
| 自车回波占比 | **< 5%**（不处理是 100%） |
| 静止与旋转时的定位一致性 | 无明显跳变 |

## 7. 本版修掉的 7 个 bug（都值得记住）

| # | Bug | 症状 | 根因 |
|---|---|---|---|
| 1 | 参数类型 | 节点启动即崩 | launch 传 `gimbal_rate:=0` 被解析为整数，与 double 声明冲突 |
| 2 | 参考时刻取错 | 去畸变反而更差 | 按帧起始归一化，下游却用帧结束的 TF |
| 3 | **TF 查询静默失败** | 补偿基准错误 | 扫描戳"发布时刻"超前于最新 TF，`except` 吞掉异常返回 0 |
| 4 | **单线程执行器死锁** | TF 始终查不到 | `lookup_transform(timeout)` 阻塞唯一线程，TF 回调无法收数据，滞后达 0.16 s |
| 5 | **多 deque 竞态** | `np.interp` 崩溃 | 物理线程逐个 append，扫描线程读到长度不一致的中间状态 |
| 6 | 自车滤波顺序错 | 扫描全空 | 先 `min()` 再滤波，环境已被覆盖且不可恢复 |
| 7 | 未命中值被裁剪 | 生成虚假远墙 | `np.clip(inf, lo, hi)` 把 `inf` 变成 `hi=8.0` |

> 其中 3、4、5 是**并发与时间边界**问题，不写测试很难发现；
> 6 是**顺序**问题，逻辑上完全自洽但在真实管线里必错。
> 这三类问题是**真车上同样会遇到的**，比单纯的算法错误更值钱。

## 9. 已知局限（下一步）

| 局限 | 影响 | 补法 |
|---|---|---|
| 雷达是**理想 2D 切片**，没有真实 3D 点云 | 自遮挡只建模了"近距回波"，未建模高度带切片 | 接真实 Mid-360 rosbag 回放 |
| IMU 无噪声、无零偏 | 去畸变效果偏乐观 | 加 gyro 噪声与零偏 |
| 输出栅格量化 0.5° | 残差 ~0.05 m | 已用 720 束缓解 |
| 未验证**云台锁定/旋转模式切换** | 交战态未测 | 加 `/cmd_gimbal_rate` 时序测试 |
| 底盘自旋时的联合补偿未单独验证 | 小陀螺场景 | 加底盘自旋 + 云台反转的测试 |

## 10. 一句话总结

> **倒置 + 同轴 + 随云台转是可以做的，但两件事不能省：**
> **用雷达内置 IMU 做旋转去畸变（180°/s 时误差降 65%），
> 以及在取最近点之前剔除自车点（不处理则 100% 回波都是自己）。**
