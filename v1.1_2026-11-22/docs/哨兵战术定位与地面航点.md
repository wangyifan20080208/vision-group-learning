# 哨兵战术定位与地面航点（RMUL 2027）

> 前提：**哨兵只在平地作战，不涉及高地；高地由步兵负责。**
> 产物：`maps/rmul2027/sentry_waypoints.json`
> 工具：`code/rm_nav_sim/tools/sentry_waypoints.py`

---

## 1. 分队分工

| 兵种 | 负责的控制区 | 数量 |
|---|---|---|
| **哨兵** | **中央控制区**（唯一的地面控制区） | 1 |
| 步兵 / 重装 | 红方高地、蓝方高地（0.2 m 台阶上） | 2 |

## 2. 团队胜利路径

控制度机制（详见规则 3.3.4）：

```
每控制一处控制区 → 对方每秒扣 1 点控制度
双方各 600 点
```

| 控制区数量 | 300 秒后的效果 |
|---|---|
| 1 处 | 对方扣 300，剩 300 → **只能比大小** |
| **2 处** | 对方扣 600 → **直接归零，立即获胜** |

**所以：哨兵守住中央 + 步兵拿下任意一处高地 = 速胜条件达成。**

> **哨兵守中央，不是"一个次要任务"，而是速胜条件的整整一半。**

## 3. 哨兵行为规范（守点型）

```
开局
 └─► 直奔中央控制区 (0,0)
      └─► 驻守：在区内小幅变位，避免被预瞄
           ├─► 发现敌人 → 交战（自瞄）
           ├─► 血量 < 30% → 撤到补给区
           │                 └─► 4 秒回满 → 返回中央
           └─► 被击毁 → 复活后先去补给区解除虚弱，再回中央
```

### 三条铁律

**① 不追击**

占领进度机制明确规定：

> 当双方均不激活一处非中立状态的控制区，双方对该处控制区的占领进度均每秒减少 1。

**哨兵一离开中央，自己的进度就开始衰减。** 所以追杀残血敌人 = 用控制度换一个击杀，通常是亏的。

**哨兵的 KPI 是「在控制区内的秒数」，不是击杀数。**

**② 每个状态必须超时**

哨兵全自动、无操作手。逻辑一旦卡住就是 5 分钟不动。所有状态加 `max_duration`，超时回中央。

**③ 不在场内做多机协调**

规则表 3-5：**哨兵多机通信不允许**。

所以哨兵无法在比赛中和步兵沟通。**"哨兵守中央、步兵打高地"这个分工必须在赛前定死**，运行时各干各的，靠站位自然错开。

## 4. 航点

| 名称 | 坐标 | 类型 | 说明 |
|---|---|---|---|
| 中央守点 | **(0.00, 0.00)** | primary | 主任务，控制区正中 |
| 变位点 | (0.00, 0.90) | shift | 区内变位，避免被预瞄 |
| 变位点 | (0.00, −0.90) | shift | 同上 |
| 己方补给区 | **(−4.75, 3.00)** | heal | 自由格占比 82%，从中央可达 |

补给区范围（来自 CAD）：`x ∈ [−6.0, −3.5]`，`y ∈ [2.0, 4.0]`
回血速度：**25% 上限血量/秒 = 100 HP/s → 4 秒回满**（哨兵上限 400）

> 己方半场由 `OWN_SIDE` 参数决定，需与官方场地图核对红蓝方向。

## 5. 需要提前规划的威胁

中央控制区**被两处高地夹在中间**：

```
        [红方高地 0.2m]   [中央控制区]   [蓝方高地 0.2m]
              x=-2.5           x=0            x=+2.5
```

### 问题

1. **高地上的敌人有高度优势**，可以俯射中央区
2. **高地增益点给 25% 防御增益**（规则 3.3.5.1），而中央控制区**不给防御增益**
   → 站在高地上的敌人比中央的哨兵更"肉"

### 应对

| 手段 | 说明 |
|---|---|
| **区内变位** | 不要固定停在 (0,0)，用 3 个变位点轮换 |
| **优先打高地目标** | 高地上的敌人威胁最大 |
| **快速回血循环** | 400 血 + 100 HP/s 回血 = 能打消耗战 |
| **不恋战** | 血量低于阈值就走，宁可丢几秒进度 |

### 云台俯仰余量

高地高 0.2 m。3 m 距离上的仰角 = `atan(0.2/3) ≈ 3.8°`，完全在云台俯仰范围内，
**自瞄的弹道解算不需要为高地做特殊处理**。

```bash
# 己方在 -x 侧
python3 tools/sentry_waypoints.py maps/rmul2027/map.yaml maps/rmul2027 -x

# 己方在 +x 侧
python3 tools/sentry_waypoints.py maps/rmul2027/map.yaml maps/rmul2027 +x
```

**红蓝方向需与官方场地图核对**——CAD 模型完全 180° 对称，几何上无法区分。
