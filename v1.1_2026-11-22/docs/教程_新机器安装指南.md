# 新机器安装指南（Ubuntu 22.04 + ROS 2 Humble + 导航仿真）

> 目标：从一台**空机器**到**跑起导航仿真**，全程约 1.5–2 小时（大部分在等下载）。
> 如果网络好，40 分钟能搞定。

---

## 0. 动手前先确认三件事

### ① 这台机器干什么用

| 用途 | 装什么 | 说明 |
|---|---|---|
| **装在车上**（机器人主控） | **Ubuntu 原生** | 要接雷达网口、串口、CAN，WSL 折腾不起 |
| 只在桌面调参、写代码 | Ubuntu 原生 或 WSL2 都行 | WSL2 更省事，但显卡/网络有限制 |

**本文按"Ubuntu 原生"写**，WSL2 的差异见第 10 节。

### ② 磁盘够不够

```bash
df -h /
```

**至少 40 GB 空闲。** 分配参考：

| 项 | 占用 |
|---|---|
| Ubuntu 系统 | 8 GB |
| ROS 2 Desktop | 3 GB |
| Nav2 + 依赖 | 2 GB |
| 编译产物 | 1 GB |
| 地图和日志 | 2 GB |
| 余量 | 20 GB |

### ③ 有没有独立显卡

```bash
lspci | grep -i vga
ls /dev/dri
```

| 结果 | 影响 |
|---|---|
| 有 `/dev/dri` | 正常，RViz 有 GPU 加速 |
| 没有 | **不影响**本项目（我们不用 Gazebo，RViz 走软件渲染也能跑） |

> **重要**：本项目**不需要装 Gazebo**。省下这一步能少踩一半的坑。

## 1. 装 Ubuntu 22.04

> 已经装好 Ubuntu 22.04 的，跳到第 2 节。
> 已经是 24.04 的，**必须重装成 22.04**——ROS 2 Humble 只支持 22.04。

### 1.1 做启动 U 盘

1. 下载镜像：https://releases.ubuntu.com/22.04/ （选 `ubuntu-22.04.5-desktop-amd64.iso`，约 4.7 GB）
2. 下载 Rufus：https://rufus.ie/
3. Rufus 里选 U 盘 → 选 ISO → 开始（会清空 U 盘）

### 1.2 装系统

1. 插 U 盘，开机按 `F12`/`F2`/`Del`（不同机器不一样）进启动菜单
2. 选 U 盘启动
3. 选 **Install Ubuntu**
4. 分区建议（新手直接选第一项"清除整个磁盘并安装"最省事）：

| 挂载点 | 大小 | 类型 |
|---|---|---|
| `/` | 剩余全部 | ext4 |
| `/boot` | 1 GB | ext4 |
| swap | 8 GB（内存的 1 倍） | swap |

5. **记住用户名和密码**，后面 sudo 要用

### 1.3 装完先做三件事

```bash
# ① 更新系统
sudo apt update && sudo apt upgrade -y

# ② 装基础工具
sudo apt install -y build-essential cmake git curl wget vim \
    python3-pip python3-venv net-tools htop

# ③ 确认版本
lsb_release -a      # 必须是 22.04
```

## 2. 换国内镜像源（**必做，否则下载慢十倍**）

```bash
# 备份
sudo cp /etc/apt/sources.list /etc/apt/sources.list.bak

# 换成清华源
sudo sed -i 's|http://archive.ubuntu.com|https://mirrors.tuna.tsinghua.edu.cn|g; s|http://security.ubuntu.com|https://mirrors.tuna.tsinghua.edu.cn|g' /etc/apt/sources.list

sudo apt update
```

验证：`sudo apt update` 的输出里应该出现 `mirrors.tuna.tsinghua.edu.cn`。

## 3. 装 ROS 2 Humble

### 3.1 加 ROS 源（用清华镜像，不然很慢）

```bash
# 密钥
sudo apt install -y curl gnupg lsb-release
sudo curl -sSL https://raw.githubusercontent.com/ros/rosdistro/master/ros.key \
  -o /usr/share/keyrings/ros-archive-keyring.gpg

# 如果上面这行超时（GitHub 被墙），用这个国内镜像：
# sudo curl -sSL https://mirrors.tuna.tsinghua.edu.cn/rosdistro/ros.key \
#   -o /usr/share/keyrings/ros-archive-keyring.gpg

# 源
echo "deb [arch=$(dpkg --print-architecture) signed-by=/usr/share/keyrings/ros-archive-keyring.gpg] \
  https://mirrors.tuna.tsinghua.edu.cn/ros2/ubuntu $(. /etc/os-release && echo $UBUNTU_CODENAME) main" \
  | sudo tee /etc/apt/sources.list.d/ros2.list

sudo apt update
```

### 3.2 安装

```bash
sudo apt install -y ros-humble-desktop
```

约 2–3 GB，慢的话泡杯茶。

### 3.3 配置环境

```bash
echo "source /opt/ros/humble/setup.bash" >> ~/.bashrc
source ~/.bashrc
```

### 3.4 验证

```bash
ros2 pkg list | wc -l
```

**应该 300 以上。** 少于 100 说明没装全。

```bash
# 经典测试：开两个终端
# 终端 A
ros2 run demo_nodes_cpp talker
# 终端 B
ros2 run demo_nodes_py listener
```

看到 `I heard: [Hello World: 1]` 就成功了。`Ctrl+C` 退出。

## 4. 装 Nav2 和依赖

```bash
sudo apt install -y \
  ros-humble-navigation2 \
  ros-humble-nav2-bringup \
  ros-humble-slam-toolbox \
  ros-humble-tf2-tools \
  ros-humble-xacro \
  ros-humble-joint-state-publisher
```

### 4.1 初始化 rosdep（**这里最容易卡**）

```bash
sudo rosdep init
rosdep update
```

**如果 `rosdep update` 卡住或报错**（国内常见）：

```bash
# 方案 A：用国内镜像
pip3 install rosdepc
sudo rosdepc init
rosdepc update

# 方案 B：手动换源
sudo mkdir -p /etc/ros/rosdep
# 编辑 ~/.ros/rosdep/sources.list.d/20-default.list，把 raw.githubusercontent.com
# 换成 ghproxy 镜像，例如：
#   https://ghfast.top/https://raw.githubusercontent.com/ros/rosdistro/master/rosdep/...
```

本项目**大部分依赖已能用 apt 装**，rosdep 失败通常不影响第 8 节的验证。

## 6. 把代码弄到机器上

**⚠️ 不要在小电脑上直接 `git clone` GitHub**——国内大概率卡死或超时。

### 方案 A：U 盘拷贝（最稳）

1. 在旧电脑上把整个 `vision-group-learning` 文件夹拷进 U 盘
2. U 盘插到新机器，复制到 `~/`

```bash
cp -r /media/$USER/你的U盘/vision-group-learning ~/
```

### 方案 B：先在 Windows 上 clone，再拷进 WSL/Ubuntu

```powershell
git clone https://github.com/wangyifan20080208/vision-group-learning.git
```

然后：
```bash
cp -r /mnt/d/vision-group-learning ~/
```

### 方案 C：走镜像站

## 7. 编译工作区

```bash
# 建工作区
mkdir -p ~/rm_ws/nav_sim_ws/src
cd ~/rm_ws/nav_sim_ws

# 把代码包放进去
cp -r ~/vision-group-learning/v1.1_2026-11-22/code/rm_nav_sim src/

# 地图和配置
mkdir -p maps config
cp -r ~/vision-group-learning/v1.1_2026-11-22/maps/rmul2027 maps/
cp ~/vision-group-learning/v1.1_2026-11-22/maps/rmul2027/map.yaml maps/rmul2027/ 2>/dev/null

# 编译
cd ~/rm_ws/nav_sim_ws
source /opt/ros/humble/setup.bash
colcon build --symlink-install
```

**成功标志：**

```
Summary: 1 package finished [12.3s]
```

**失败常见原因：**

| 报错 | 原因 | 解决 |
|---|---|---|
| `colcon: command not found` | 没装 | `sudo apt install python3-colcon-common-extensions` |
| `Could not find a package configuration file provided by "rclpy"` | 没 source ROS | 先 `source /opt/ros/humble/setup.bash` |
| `ament_cmake` 找不到 | 同上 | 同上 |

### 7.1 配置环境变量

```bash
echo "source ~/rm_ws/nav_sim_ws/install/setup.bash" >> ~/.bashrc
source ~/.bashrc
```

## 8. 首次运行验证（五步，逐级）

**不要跳步。** 每一步失败就停下来修，别往下走。

### 第 1 步：包能被找到

```bash
ros2 pkg list | grep rm_nav_sim
ros2 pkg executables rm_nav_sim
```

应该看到 `rm_nav_sim sim_node` 和 `rm_nav_sim deskew_node`。

### 第 2 步：地图文件在

```bash
ls ~/rm_ws/nav_sim_ws/maps/rmul2027/
# 应该有 map.pgm 和 map.yaml
```

### 第 3 步：只启仿真，看话题

```bash
# 终端 A
ros2 run rm_nav_sim sim_node --ros-args \
  -p map_yaml:=$HOME/rm_ws/nav_sim_ws/maps/rmul2027/map.yaml

# 终端 B
ros2 topic list
ros2 topic hz /scan
ros2 topic echo /scan --once | head -20
```

**通过标准**：`/scan` 频率约 10 Hz，`ranges` 里有非 `inf` 的数值。

### 第 4 步：启动完整导航 + RViz

```bash
bash ~/vision-group-learning/v1.1_2026-11-22/code/scripts/run_rviz_tilted.sh
```

**通过标准**：
- RViz 打开，能看到场地地图
- 车在左下角开始位置
- 激光扫描贴合地图轮廓

### 第 5 步：发一个导航目标

新终端：

```bash
source ~/rm_ws/nav_sim_ws/install/setup.bash
ros2 action send_goal /navigate_to_pose nav2_msgs/action/NavigateToPose \
  "{pose: {header: {frame_id: map}, pose: {position: {x: 5.38, y: -2.88}, orientation: {w: 1.0}}}}" --feedback
```

**通过标准**：`Goal finished with status: SUCCEEDED`

## 9. 安装阶段常见失败排查

| 症状 | 原因 | 解决 |
|---|---|---|
| `E: Unable to locate package ros-humble-*` | ROS 源没加成功 | 重做第 3.1 节，`apt update` 看有没有报错 |
| `apt update` 卡在 `raw.githubusercontent.com` | GitHub 被墙 | 换清华 ROS 源 |
| `ros2: command not found` | 没 source | `source /opt/ros/humble/setup.bash` |
| `colcon build` 报 `set -u` 相关 | 脚本里有 `set -u` 和 ROS 冲突 | 脚本开头改 `set +u` |
| RViz 打开黑屏 | 显卡驱动 | 试 `LIBGL_ALWAYS_SOFTWARE=1 rviz2` |
| `/scan` 没有数据 | 地图路径错 | 用绝对路径 `$HOME/...` |
| 编译后 `ros2 pkg list` 找不到包 | 没 source install | `source install/setup.bash` |

### 9.1 一个万能诊断脚本

```bash
cat > ~/check_env.sh <<'EOF'
#!/usr/bin/env bash
echo "=== 系统 ==="; lsb_release -ds; uname -r
echo "=== 磁盘 ==="; df -h / | tail -1
echo "=== ROS ==="; echo "${ROS_DISTRO:-未 source}"
ros2 pkg list 2>/dev/null | wc -l
echo "=== 工作区 ==="; ls ~/rm_ws/nav_sim_ws/install 2>/dev/null | head -3 || echo 未编译
echo "=== 包 ==="; ros2 pkg list 2>/dev/null | grep -c rm_nav_sim
echo "=== Python ==="; python3 -c "import numpy,yaml,PIL;print('deps ok')" 2>&1
EOF
bash ~/check_env.sh
```

## 10. 如果用 WSL2（差异部分）

### 10.1 装 WSL2

```powershell
wsl --install -d Ubuntu-22.04
wsl --set-default Ubuntu-22.04
```

装完从开始菜单打开 "Ubuntu 22.04"，后面的 2–9 节和原生 Ubuntu **完全一样**。

### 10.2 三个差异

| 项 | 原生 Ubuntu | WSL2 |
|---|---|---|
| 图形界面 | 有 | **没有**（RViz 需要 WSLg，Win11 自带） |
| `/dev/dri` | 通常有 | **没有** | 
| 网络 | 直接 | NAT，接雷达要额外配 |
| 文件性能 | 快 | **`/mnt/d` 下极慢**，代码要放在 `~` |

### 10.3 WSL2 注意

- **代码一定放 `~/`，不要放 `/mnt/d/`**，否则编译慢 10 倍
- RViz 需要 Win11（WSLg）；Win10 要装 VcXsrv
- 没有 `/dev/dri` 不影响本项目（不用 Gazebo）
