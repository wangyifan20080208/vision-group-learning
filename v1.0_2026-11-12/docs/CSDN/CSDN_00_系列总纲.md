# CSDN 系列总纲：《从零开始学机器人导航（RoboMaster 版）》

> 定位：写给"想学导航但不知道从哪下手"的 RM 视觉组新人
> 前提假设：**读者只会一点 Python，没装过 ROS，没做过机器人**
> 载体：CSDN 连载，每篇独立可读，合起来是一条从零到实车的完整路径

---

## 一、为什么是 14 章，不是 8 章

我最初规划了 8 章，从"别急着装 Gazebo"开始。

但拿给一个真正零基础的同学看，他的第一个问题是：**"ROS2 是什么？我怎么装？"**

所以加了一个「第 0 部分·准备」，四章，把地基铺到"能跑起一个 ROS2 节点"为止。

```
第 0 部分  准备       4 章   从装系统到第一个 ROS 节点
第 1 部分  理解       4 章   导航到底在解决什么问题
第 2 部分  跑通       4 章   地图、仿真、定位、参数、调试
第 3 部分  进阶       2 章   全向底盘+旋转云台、上真车
```

**总计 14 章，约 3.2 万字。** 每章都有能跑出来的产出，不是纯理论。

## 三、三条阅读路径

| 路径 | 适合谁 | 怎么读 | 时间 |
|---|---|---|---|
| **A. 完全零基础** | 大一，只会 Python | 01 → 13 顺序读 | 3–4 周，每天 2h |
| **B. 有 ROS2 基础** | 装过 ROS、跑过 turtlebot | 跳过 01–04，从 05 开始 | 1.5 周 |
| **C. 已经在做，只查问题** | 卡在某个具体错误 | 直接看 11 章的"现象→原因→查法"表 | 半小时 |

每章开头都会写清楚"**这一章假设你已经会什么**"，方便跳读。

## 四、每章的统一结构

```
0. 本章你会得到什么（一张图 / 一段代码 / 一个数）
1. 问题：我遇到了什么
2. 原理：为什么是这样（配图，概念不超过 3 个）
3. 做法：代码 + 命令，能复制粘贴
4. 验证：怎么确认自己是对的（给具体数值标准）
5. 坑：这一章独有的坑
6. 预告：下一章讲什么
```

**"验证"这一节是这个系列的核心竞争力。**
网上大部分教程只教你"敲什么命令"，不教你"怎么知道成功了"。我每章都会给具体数字标准，比如"扫描与地图的平均误差应小于 2 cm"。

## 六、写作与发布顺序（重要）

**写作按技术依赖，发布按阅读顺序。**

写作顺序建议：
```
06 → 07 → 08   （硬核三连，已有素材，先写完）
→ 09 → 10 → 11 （顺下来）
→ 01 → 02 → 03 → 04 → 05 （回头补基础）
→ 12 → 13      （进阶，等硬件确认）
```

发布顺序：**01 先发**。基础篇决定了新读者会不会留下来；但如果先发 06，会有大量人问"ROS2 怎么装"。

## 七、系列的技术主线（一句话）

> **用一个能验证的最小系统，把导航的每一层单独拆开看清楚，再把它们装回去。**

这句话会出现在每章开头，作为整个系列的锚点。

---

## 八、给读者的一句提醒

这个系列**不会**让你"照抄就能比赛获奖"。

它只保证一件事：**你读完能自己判断问题出在哪一层，而不是到处改参数碰运气。**

这也是我写它的原因——我踩过的坑，你少踩一遍，省下来的时间够你多做两轮实测。
